> **EVIDLINK** is an enterprise-grade, multi-jurisdictional criminal intelligence and forensic analysis platform designed for law enforcement agencies (CBI, NIA, ED, State Special Cells) and intelligence analysts. It transforms fragmented multi-modal evidentiary data (FIR complaints, Call Detail Records, FASTag/ANPR toll scans, bank Hawala ledgers, and cell tower dumps) into actionable, explainable intelligence with mathematical network topology analysis.

---

## 🌟 Key Capabilities & Architecture

### 1. 🕸️ Tactical Topological Graph & Link Analysis
- **Dynamic Bipartite Clustering**: Automatically segments disparate entities into functional criminal syndicates (e.g., *Cluster Alpha: Ground Transport & Logistics* vs. *Cluster Beta: Corporate Shells & Hawala Escrows*).
- **Structural Bridge & Bottleneck Isolation**: Identifies critical criminal intermediaries and brokers using mathematical **Betweenness Centrality (e.g., Vikram S. `PER-002` scoring 98/100)**.
- **Shortest Path & Network Traversal**: Calculates multi-hop links between key kingpins, mules, and shell companies.

### 2. 📡 Live SIGINT & Intercept Telemetry Stream
- **Real-Time Sensor Ingestion**: Live streaming ticker correlating ANPR optical plate detections, burner phone IMSI hops, and FIU-IND suspicious transaction reports (STRs).
- **Tactical Audio Synthesizer**: Native Web Audio engine emitting sub-second radar pings and critical intelligence alerts.

### 3. 🔍 Explainable AI & Provenance Engine (Zero Black-Box)
- **Deterministic Lead Generation**: Generates prioritized hypothesis cards (*Critical, High, Medium, Low*).
- **Why This Lead? Provenance Modal**: Gives analysts 100% transparent audit trails, highlighting timestamps, source documents, and cryptographic chain-of-custody verification.

### 4. 📂 Multi-Domain Forensic Workbenches
- **Telecom & CDR Forensics**: Pre-movement call burst analysis, IMEI-SIM hopping detection, and cell tower handoff matrices.
- **Financial Flows & Hawala Layering**: Multi-tier fund tracking across shell accounts with one-click *ED Asset Freeze Order* generation.
- **ANPR & Geospatial Correlation**: Optical toll plaza surveillance and 50-meter suspect co-location detection along national highway corridors.
- **Entity Resolution & De-Anonymization**: Fuzzy multi-attribute matching (PAN, Passport, Phone Hash, Location) with interactive merge/reject workbench.
- **Court-Admissible Reports**: Section 65B Indian Evidence Act compliant dossier generator with digital signatures and official agency crests.

## 🚀 Quick Start (Local Setup)

### Prerequisites
- [Node.js](https://nodejs.org/) (v18.0 or later)
- [npm](https://www.npmjs.com/) or [bun](https://bun.sh/)

### Installation & Execution
```bash
# 1. Clone the repository
git clone https://github.com/243134-tech/Evidlink.git
cd Evidlink

# 2. Install dependencies
npm install --legacy-peer-deps

# 3. Start the tactical dev server
npm run dev
```

Open your browser and navigate to:
```text
http://localhost:3000/
```
